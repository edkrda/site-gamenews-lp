# Game News

## Tema
Site acadêmico sobre jogos digitais, novidades, lançamentos e cultura gamer.

## Integrantes
- Eduarda de Almeida Miranda - RA: 249607

## Turma N2

## Páginas do Projeto
- Home (`index.html`)
- Galeria / Novidades / Lançamentos (`galeria.html`)
- Contato (`contato.html`)

## Tecnologias Utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript
- GitHub

## Funcionalidades
- Menu responsivo com Bootstrap Navbar
- Carrossel Bootstrap na página Home
- Galeria reduzida com 4 cards de jogos e imagens
- Filtros de categorias na galeria usando JavaScript
- Formulário de contato completo com nome, e-mail, telefone, assunto e mensagem
- Validação HTML5 e JavaScript no formulário
- Botão de envio e botão de limpar campos
- Mapa incorporado com iframe na página de contato
- Informações de atendimento, endereço FACENS, telefone, e-mail e redes sociais
- Botão voltar ao topo
- Efeitos visuais em cards, botões e imagens
- Layout responsivo com Bootstrap Grid e Flexbox
