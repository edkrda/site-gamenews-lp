Game News

O Game News é um site sobre jogos com estética fofa. A página reúne uma seleção pequena de destaques, galeria com filtros e uma área de contato.

Na construção foram usados HTML5 semântico, Bootstrap, Flexbox, CSS externo e JavaScript para deixar o projeto responsivo e funcional sem exagerar na quantidade de elementos.
